Quién escribe esta tabla {% if clave == 'tcm' %}

El costo de Baguette y CupCake es una fórmula que trae el costo de la última hornada desde su hoja de costo. Su precio de venta es el precio de referencia que la administración define en esa misma hoja de costo.

El costo de los productos que se compran para revender lo actualiza el robot una vez al día con la API de catálogo del proveedor. Si la lectura falla, la celda no se toca y conserva el último costo. Su precio de venta es una fórmula sobre ese costo.

El nombre técnico es la llave con que las demás hojas buscan el producto: solo se cambia con una migración.

{% else %}

El costo del paquete lo actualiza el robot una vez al día con la API de catálogo del proveedor. Si el proveedor no responde desde la nube, el robot usa el respaldo manual de Drive; si tampoco hay respaldo, la celda no se toca.

El costo por gramo o pieza es una fórmula: el costo del paquete dividido entre su contenido. Las hojas de costo lo multiplican por los gramos de cada receta.

El nombre de la materia prima es la llave con que las demás hojas la buscan: solo se cambia con una migración.
